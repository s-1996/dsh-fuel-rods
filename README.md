# 核燃料棒反应堆

一个纯 Client 的 DSH Web 背景插件：实时渲染圆形控制棒阵列，读取当前会话已有的 Token 投影，让堆芯随任务律动。右下角设置按钮提供指标开关、实时数值、全局背景、侧边栏同步、反应堆强度、控制棒灵敏度与运动平滑度调节，并显示会话开销估算。堆芯始终跟随会话阅读区；背景可选择只铺会话区或同步到侧边栏。

## 功能

- 透明 WebGL2 控制棒阵列（画布全屏，堆芯自适应当前会话区）：709 根棒、圆形基环、刻度、等距投影、单级 Bloom 辉光。
- 参考文件式舞台背景：`radial-gradient(ellipse at 50% 49%, 中心亮 → 43% → 78% 边缘暗)`，默认严格铺满当前会话区，不再向左右侧边栏投出阴影。
- 全局背景支持 **侧边栏同步**：关闭时侧边栏保持宿主原色；打开后同一径向底色延伸至侧边栏，但控制棒尺寸仍按会话区计算。
- 舞台背景可选 **黑色 / 松绿 / 砖红 / 米黄**：只改变舞台底色，不修改燃料棒颜色、指标开关与反应堆强度。
- 光晕与横向淡出限制在会话区内；底部柔和淡出，避免压住输入框。
- 点击穿透，不拦截宿主操作。
- 指标驱动：
  - **Token 用量**：控制振幅和堆芯能量；Token 增长时发出向外扩散的冲击波。
  - **缓存命中**：缓存读取占输入 Token 的比例，控制波动节奏。
  - **Token 输出速度**：按 output Token 增量与时间估算 tok/s，控制棒顶高频闪烁与能量脉动。
  - **上下文占用**：控制基础高度、暖色程度与 Bloom 强度。
- 堆芯始终按当前会话阅读区缩放：左/右侧边栏打开时随可用宽度收窄，关闭后放大，并保持居中于会话区；背景是否延伸至侧边栏由开关单独控制。
- AI 运行中完整律动；待机时低幅慢速呼吸；四项指标全部关闭时只绘制静态阵列。
- 支持深色 / 浅色主题、`prefers-reduced-motion`、WebGL 上下文丢失降级。
- 右下角浮动设置按钮；菜单内可逐项开关指标、查看实时数值、切换舞台背景、开启侧边栏同步、调节反应堆强度 / 控制棒灵敏度 / 运动平滑度、恢复默认，并在页脚查看会话开销估算。
- 设置保存在当前浏览器 localStorage（自动迁移旧版 v1 开关配置）。
- 不读取对话正文、不播放音频、不联网、不写会话日志、不新增模型可见内容。

## 设置菜单

点击右下角滑杆图标打开：

- 运行状态；
- 四个指标开关（整行可点击），显示当前 Token 用量 / 缓存命中 / Token 输出速度 / 上下文数值；
- 全局背景四选一：黑色、松绿（参考文件舞台径向渐变的松绿色变体）、砖红、米黄；
- 侧边栏同步开关：关闭时背景仅覆盖会话区，打开后延伸到侧边栏，控制棒尺寸不变；
- 反应堆强度 0–100%，默认 60%；
- 控制棒灵敏度 0.3×–3.0×，默认 1.4×，步进 0.1；
- 运动平滑度 0–95%，默认 75%；
- 页脚“会话开销”：按最近使用的模型与当前高峰/空闲时段估算，悬停可看口径；
- 恢复默认；
- WebGL 不可用时页脚会附带“静态降级”说明，不再常驻显示 WebGL2 标识。

菜单支持点击外部或 Escape 关闭；关闭后焦点回到按钮。无当前会话时按钮自动隐藏。

## 数据口径

- Token 用量：`uncachedInputTokens + cacheReadTokens + cacheWriteTokens + outputTokens`，当前会话累计。
- 缓存命中：`cacheReadTokens / (uncachedInputTokens + cacheReadTokens + cacheWriteTokens)`。
- Token 输出速度：监听 `outputTokens` 增量，结合两次增量之间的时间做滚动估算，并按秒衰减；数值为 `tok/s`，不是服务端计费口径。
- 上下文：`(projectedTokens ?? pressureTokens) / contextWindow`，限制在 0–100%。
- 会话区尺寸：读取当前 `[data-conversation-scroll]` 的宽度与水平中心，通过 ResizeObserver 跟随侧边栏动画；舞台径向背景直接按该矩形铺满，WebGL 端对 width/center 做弹性插值，避免生硬跳变。
- 控制棒灵敏度：参考文件的 `gain` 范围 0.3–3.0，默认 1.4×；以 1.4× 为中性基线缩放振幅与颜色热度，最高灵敏度下限制峰值避免棒体冲出画面。
- 运动平滑度：参考文件的 `0.45 + smoothing × 0.53` 帧衰减公式，换算为秒级指数平滑；默认 75%，待机时以约 35% 速率呼吸。
- 会话开销：`未命中输入 × miss 单价 + 缓存读取 × hit 单价 + 缓存写入 × miss 单价 + 输出 × 输出单价`，按 1M token 单价换算。缓存写入按缓存未命中输入计费。
- 价格表使用 DeepSeek 官方 2026-10-18 公示价：`deepseek-flash` 与 `deepseek-v4-pro`；中文界面显示人民币，英文界面显示美元。高峰时段按北京时间周一至周五 09:00–12:00、14:00–18:00 估算，未接入中国法定节假日日历。
- 开销是**当前时段、最近使用模型**的近似值，不按每笔请求的历史峰谷分别计价；实际费用以 DeepSeek 平台账单为准。

数据来自 `token-meter` 已注册的 `tokenUsage`、`contextPressure` 与 `modelSelection` 投影。缺数据时菜单显示 `—`，渲染使用中性值。

## 性能与降级

- 单级 Bloom，场景 FBO 约 1.5× 超采样；Canvas 绘制缓冲区限制在约 240 万像素，场景 FBO 限制在约 500 万像素。
- 运行中约 60fps，待机约 30fps；页面隐藏时暂停。
- WebGL2 不可用或上下文丢失时显示静态 CSS 光晕，并在菜单中提示降级，不崩溃页面。

## 层级说明

`shell.overlay` 位于所有列的顶层，因此这是点击穿透的“氛围背景”，不是聊天面板背后的宿主壁纸。舞台径向背景以低透明度叠加在会话区上，不修改宿主主题；默认左右边界严格使用会话区测量值，不会进入侧边栏。打开“侧边栏同步”后，同一底色层扩展到整个视口，但 WebGL 堆芯仍被裁切并缩放到会话区。若需要真正的壁纸层级，需要修改宿主 shell / 主题 CSS，超出本插件范围。
